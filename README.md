# Projeto de Machine Learning — Risco de Crédito

Projeto acadêmico de Ciência de Dados com foco na construção de um pipeline preditivo para previsão de risco de crédito.

A base escolhida foi a Opção A: Risco de Crédito, cujo objetivo é prever se um cliente tende a se tornar inadimplente ou se pagará o empréstimo em dia.

## Status do projeto

Em desenvolvimento.

## Estrutura inicial

- `data/`: base de dados utilizada no projeto.
- `notebooks/`: notebook principal com EDA, tratamento, modelagem e avaliação.
- `imagens/`: gráficos e matrizes de confusão gerados durante a análise.
- `requirements.txt`: bibliotecas necessárias para execução.
